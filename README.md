# n8n Supply Chain Automation

A collection of practical supply chain automation solutions built with n8n.

The goal is simple:

> Identify repetitive, error-prone supply chain work and design lightweight automation solutions that reduce manual effort while keeping important business decisions with humans.

## Projects

### 01 — Supplier PO Exception Automation
Automating repetitive supplier purchase-order checks, exception identification, prioritization, and supplier follow-up.

### 02 — Inventory & Production Planning Automation
Automating the process of bringing together demand, inventory, in-transit supply, product status, and production constraints to determine production requirements.

## Approach

Each project follows a business-first approach:

1. Understand the supply chain problem
2. Document the current manual process
3. Identify data inputs and business rules
4. Design the automation architecture
5. Build the workflow in n8n
6. Keep human decisions where judgment is required
7. Test the workflow with realistic scenarios
8. Document the solution and lessons learned

## Tools

- n8n
- Python where appropriate
- Excel / CSV
- APIs and webhooks
- AI / LLMs where they provide genuine value
- GitHub for documentation and version control
